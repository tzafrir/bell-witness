# The T4 impossibility theorem (Step 5 — resolves lab-note v3 next-step #3)
THEOREM. In any substrate model where (i) preparation is measurement-setting-
independent and (ii) each party's outcome is a function of a side-local
configuration, Bell violation implies the existence of an A-side observable
C (a function of A-side micro-state) whose joint statistics with A depend on
B's setting b. Hence exact pairwise-joint no-signaling against arbitrary
environment probes ("T4-completeness") is IMPOSSIBLE while violating.
PROOF CHAIN (two prior results compose):
1. Leak proposition (proved): if the A-side configuration law were
   b-invariant, conditioning on it factorizes P(A,B|a,b) into LHV form,
   so S <= 2. Contrapositive: violation => A-side law depends on b.
2. A b-dependent configuration law means some measurable functional of the
   A-side configuration has b-dependent statistics; let C be that
   functional (the optimal detector of the leak law). P(A,C|a,b) then
   depends on b. QED.
COROLLARY (the axiom forced). The only escape is that no physical system
can realize C: micro-records of the A-side configuration must be
in-principle inaccessible. Classical substrates must POSTULATE
micro-inaccessibility; quantum mechanics gets it structurally — tensor-
factor subsystems have no underlying configuration whose law could be
b-dependent. The axiom-triad dyad cannot be closed by any rule class:
the residual is a theorem-level obstruction, not a search failure.
SCOPE. Classical configurations; b-independent preparation; outcome
functionality (incl. stochastic outcomes via local noise variables).
Numerical support: leak law (0/7 suppressed, minimizer 26-sigma), mechanism
law on two path families (mixing + intensive), envelope open at S->2+.
CONSEQUENCE FOR THE PAPER. The thesis upgrades: it is not merely that the
substrate imports quantum theorems as axioms — it is that at least one of
those axioms (micro-inaccessibility) is FORCED by a theorem, and the
experimental discriminator (L_exp > 0 for accessible environment records)
is its operational shadow. Either nature hides classical records perfectly,
by law, or there are no classical records.
